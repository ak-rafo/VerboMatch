# ✅ Verbo Match · iPhone test checklist

Run this on your **real iPhone** after every update (about 10 minutes).
Tick each box. If something fails, take a screenshot and note the step number.

## 0 · Install the update
- [ ] All changed files are uploaded to GitHub, and the **Actions** tab shows a green ✅.
- [ ] `sw.js` has a new `VERSION` number (e.g. `verbo-match-v19` → `v20`).
- [ ] With Wi-Fi or signal: open the app from the Home Screen, close it (swipe up), and open it again.
- [ ] The new feature from this update is visible. If not, close and reopen once more.

## 1 · Start-up & layout
- [ ] The app opens to the last language you used (🇧🇷 or 🇪🇸).
- [ ] No loading spinner stays on screen for more than 2 seconds.
- [ ] Header: title, PT/ES switch, **Aa** and **🔊** buttons all visible and not overlapping.
- [ ] Bottom bar sits flush at the bottom on **every** tab (check Match with 6 pairs).
- [ ] Turn the phone sideways: header becomes slim, nothing is cut off.

## 2 · Match tab
- [ ] Tile match: play one full round, finish screen appears, **Próxima rodada / Siguiente ronda** works.
- [ ] Memory flip and ⌨️ Type it each start a round.
- [ ] Type it: the iPhone keyboard opens, accent buttons (á ç ñ…) insert letters, **Check** works.
- [ ] Daily bar shows level, streak, today's count, and **Review now** (if verbs are due).

## 3 · Other tabs
- [ ] Verb Bank: list is A–Z; tap a verb → pop-up opens, scrolls by itself, ✕ closes it.
- [ ] Grammar: guide scrolls; **Fill the Blank**, **Sentence Match**, **🧱 Build** each start.
- [ ] Vocab: Learn search finds “knee”; Body, Map, Family, Odd and Stories each open.
- [ ] Gírias / Jerga: Slang, Phrases and Idioms tabs open; tapping a term opens its card.
- [ ] Stats: badges and level panel appear; **⬇️ Back up progress** saves a file to Files.

## 4 · Sound
- [ ] Ring/silent switch is **on** (not silent) and volume is up.
- [ ] Tapping 🔊 on a word speaks it. Slow / Relaxed speed sounds slower.
- [ ] A story plays line by line with **▶️ Play story**.

## 5 · Display (Aa)
- [ ] 🌙 Dark: every tab is readable (no white boxes with white text).
- [ ] A++ text size: tiles and buttons still fit; nothing overlaps the bottom bar.
- [ ] Settings stay after closing and reopening the app.

## 6 · Offline
- [ ] Turn on **Airplane Mode**, close the app, reopen it: it loads and a round can be played.
- [ ] Switch language while offline: the other language loads too.
- [ ] Turn Airplane Mode off.

## 7 · Progress is safe
- [ ] Your streak, XP level and mastered count are the same as before the update.

**Found a problem?** Note: iPhone model, iOS version (Settings → General → About), the step number, and a screenshot.
